# AJ-AI VideoExpress Animal Story Agent

A personal workflow for producing cinematic, whimsical animal stories as vertical YouTube Shorts with VideoExpress AI.

## What this repo is for

This is an original workflow adapted to Janish's creative preferences: animal protagonists, cinematic visual storytelling, 9:16 as the default, scene-by-scene image and video prompts, optional narration, and a reliable final timeline check.

It is a prompt and production guide. It does not control VideoExpress automatically; use it with a browser-capable agent that can operate VideoExpress.

## Files

- [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md) — paste into your browser-capable agent before production.
- [CHECKLIST.md](CHECKLIST.md) — compact preflight, render, and final assembly checks.

## Quick start

1. Open VideoExpress AI and sign in.
2. Give the agent a story idea or ask it to invent one.
3. State the target duration if you have one. The default canvas is vertical 9:16.
4. Name any attached character or image reference and say whether it must appear in the finished story.
5. Request narration or silent video. When narration is requested, use VideoExpress's integrated voice workflow if available.
6. Let the workflow plan all scenes before rendering.
7. Review the finished timeline and export against [CHECKLIST.md](CHECKLIST.md).

## Personal defaults

- Format: vertical 9:16 Shorts.
- Genre: cinematic, whimsical, emotionally clear animal mini-stories.
- Protagonist: animal selected for each story; preserve its identity and design across scenes.
- Branding: include “AJ-AI” subtly in suitable scene details when it fits the story and remains legible.
- Prompts: detailed scene-by-scene image and motion prompts, with varied camera movement, lighting, action, and visual effects.
- Production: if the visible account supports five concurrent video jobs, never exceed five; verify actual capacity in the UI.
- Assembly: account for every rendered scene and add each exactly once to the timeline before export.

## Customization

Edit SYSTEM_PROMPT.md when you want to change your standing production preferences. Keep CHECKLIST.md in sync with any workflow changes. Never put account passwords, session tokens, API keys, or private account data in this repository.
